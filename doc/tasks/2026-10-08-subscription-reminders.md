## 二、总体架构

现有入口：`server.go` 注册管理页面和 API；`mng_pages.go` 嵌入 HTML；`scheduler_global.go` 调度；`resolveNotifyBot` / `tgNotifySendFunc` 使用既有 TG 账号。
目标：订阅独立文件位于主控 data 目录，UI → 鉴权 API → 校验与原子保存；全局调度每五分钟检查 → TG → 保存当天成功状态。
通知按主控时区的自然日去重；到期后继续每日提醒，直至续订、暂停或删除。URL 仅记录和展示，不由主控抓取。
