# 代理升级弱网返修

## 需求定义

启用方式：用户明确要求跨探针、主控的代理升级返修，符合长任务条件。用户最新指令：“返修，代理升级，反复失败，加强主控，弱网支持”。

- REQ-001：下载失败必须停在下载阶段、显示原始错误，禁止进入解压或替换当前程序。
- REQ-002：探针代理升级支持短连接分段、断线续传、跨升级尝试/进程重启保存同版本断点（24小时过期）、暂态 HTTP 错误重试、可取消退避，严格校验 Range 和完整性，保留现有程序。
- REQ-003：主控代理支持上游暂态重试、流式及时转发、断线续传，不缓存整包、不引入库、不绕过下载域名白名单或节点认证。
- REQ-004：主控域名多地址时支持故障地址切换，避免单个 CDN 地址耗尽认证超时。
- 范围：普通 Probe/Linux router 共用升级与连接、主控 HTTP 下载代理；不刷华硕、不经 SSH 替换生产程序、不修改凭据或默认路由。

## 总体架构

探针获取版本→认证→分段下载到 `.part`→完整性与运行验证→替换；失败停在原步骤。主控认证后仅代理白名单 HTTPS URL，固定内存流式转发并在上游中断时按已发送字节续传。CDN 多地址以带取消的交错连接（含 TLS）选择可用地址。
